Aula 1 de 8

Uma receita que o Claude guarda

Você consegue apontar uma tarefa do seu trabalho que vale virar skill e outra que não vale.

Toda semana você cola as mesmas instruções no Claude: o tom, o formato, o que nunca pode faltar. Basta esquecer uma linha e a resposta volta fora do padrão. Esta aula mostra o que é uma skill e em que tarefa ela compensa.

Em 1 minuto

  1. Uma skill é uma receita que você escreve uma vez e o Claude guarda.
  2. Ele abre a receita sozinho quando o pedido combina com ela.
  3. Vale para tarefa que se repete do mesmo jeito. Tarefa única não precisa.

1Você repete as mesmas instruções toda vez

Numa conversa nova, o Claude não lembra do seu jeito de trabalhar. Por isso você cola tudo de novo: o tom, o tamanho, os preços. Quando a lista é longa, sempre falta alguma coisa.

Uma skill resolve isso. Você escreve as instruções uma vez. O Claude passa a segui-las sempre que o pedido for daquele tipo.

A Débora responde uns quinze pedidos de orçamento de banho e tosa por dia. Antes, colava no Claude oito linhas com a tabela de preços e o tom da loja. Com a skill, ela cola só a mensagem do cliente.

2A skill entra sozinha quando o pedido combina

Você não precisa chamar a skill pelo nome. O Claude olha a lista das suas skills e lê uma frase curta de cada uma, a descrição. Se o pedido combina, ele abre aquela skill e segue o que está escrito.

As outras ficam fechadas e não atrapalham. Por isso dá para ter várias skills, uma para cada tarefa.

O Raul tem duas skills: uma para parecer trabalhista e outra para e-mail de andamento ao cliente. Quando ele pede "resuma a audiência de hoje para o cliente", o Claude abre só a do e-mail.

3Vale para o que se repete do mesmo jeito

Escrever uma skill leva uns vinte minutos. Compensa quando a tarefa volta toda semana e você quer o mesmo resultado sempre.

Três casos não pedem skill. A tarefa que acontece uma vez só se resolve na própria conversa. O dado que muda todo dia, como a agenda de hoje, não cabe numa receita fixa. E a regra que vale para qualquer conversa vai nas preferências pessoais, que ficam nas Configurações do app.

A Débora separou as tarefas dela em dois cartões antes de criar a primeira skill.

Teste-se

O Raul quer que o Claude escreva sempre em português formal, em qualquer conversa. Qual é o caminho?

Se travou aqui, é normalA fronteira entre skill e conversa comum confunde no começo. Use uma pergunta só: "vou pedir isso de novo, do mesmo jeito, na semana que vem?". Se a resposta for sim, a tarefa é candidata.

Pratique agora 0/3

Encontre a sua primeira skill

Pronto quando você tiver anotado uma tarefa que vale virar skill e uma que não vale, cada uma com o motivo. Cerca de 8 minutos. Dá para fazer no celular, nas Notas, ou no papel.

Nada muda no seu Claude: é só uma lista. Se nenhuma tarefa aparecer, abra suas últimas dez conversas e procure instruções que você colou mais de uma vez.

Veja a lista do Raul

Vale skill: parecer trabalhista com a mesma estrutura de cinco partes. Motivo: faço dois por semana e sempre corrijo a ordem.
Não vale: a petição do caso da metalúrgica. Motivo: é um caso único, resolvo na conversa.

Você acabou de escolher, com motivo, a tarefa que vai virar a sua primeira skill.

O que é uma skill
